# Chat Overlay - Feature Ideas

## Chat Mood Meter 🎨

**Concept:** AI-powered feature that analyzes overall chat sentiment and displays a color-changing mood indicator on the overlay.

### Moods & Colors
| Mood | Color | Description |
|------|-------|-------------|
| Warm | Orange/Gold | Friendly, supportive chat |
| Cold | Blue/Ice | Calm, chill vibes |
| Excited/Hype | Red/Fire | High energy, lots of hype |
| Angry | Dark Red | Frustrated, heated chat |
| Chill | Soft Purple | Relaxed, laid-back |
| Funny | Yellow/Green | Jokes, roasts, 💀 energy |

### How It Works
1. Browser extension scrapes chat messages
2. Messages sent to local server
3. Server calls OpenAI API to analyze sentiment of recent messages
4. Returns aggregated mood score
5. Overlay displays color-shifting mood indicator based on overall vibe

### Visual Ideas
- Subtle glow around chat box that shifts color
- Small mood indicator icon/bar
- Background gradient that slowly transitions
- Border color that pulses with chat energy
